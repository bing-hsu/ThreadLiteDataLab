## 当前项目 / Current Project

- **20261003_AB_Test**：一次 A/B 测试的收入分析。 使用 **卡方拟合优度检验** 做样
  本比例偏差（SRM）检查、检查 **SUTVA**， 再用 **两阶段 GLM** 分别分析转化率
  （Bernoulli / logistic）与付费用户平均支付金额 ARPPU（Gamma + log link），最后
  做 **MDE / 功效** 与所需样本量分析。

- **20261003_AB_Test**: a revenue analysis of an A/B test. It performs a
  **chi-squared goodness-of-fit test** for Sample Ratio Mismatch (SRM), checks
  **SUTVA**, then applies a **two-part GLM** — conversion rate (Bernoulli /
  logistic) and ARPPU (Gamma + log link) — followed by **MDE / statistical
  power** and required sample-size analysis.

## 快速开始 / Quick Start

### 方式 A：使用 uv（推荐 / Recommended）

```bash
# 1. 克隆仓库 / clone the repo
git clone <your-repo-url>
cd <your-repo>

# 2. 安装 uv（如未安装）/ install uv if needed
#    macOS / Linux:  curl -LsSf https://astral.sh/uv/install.sh | sh
#    Windows:        powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 3. 创建虚拟环境并安装全部依赖 / create env & install all dependencies
uv sync

# 4. 启动 JupyterLab / launch JupyterLab
uv run jupyter lab
```

然后打开 `20261003_AB_Test/notebook.ipynb`，点击 **Run ▸ Run All Cells** 即可复
现全部结果。

Then open `20261003_AB_Test/notebook.ipynb` and click **Run ▸ Run All Cells** to
reproduce every result.

### 方式 B：使用 pip + venv / Option B: pip + venv

```bash
# 1. 克隆仓库 / clone the repo
git clone <your-repo-url>
cd <your-repo>

# 2. 创建并激活虚拟环境 / create & activate a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. 安装锁定版本的依赖 / install the pinned dependencies
pip install -r requirements.txt

# 4. 启动 JupyterLab / launch JupyterLab
jupyter lab
```

> 提示：`requirements.txt` 由 `uv export` 生成，包含精确版本与哈希，可保证与作者
> 环境一致。 Tip: `requirements.txt` is generated by `uv export` and contains
> exact versions plus hashes, matching the author's environment.

## 关于中文字体 / A Note on Chinese Fonts

Notebook 中的图表含有中文标题。它已内置一段字体回退逻辑：会按优先级自动挑选本机
已安装的中文字体 （macOS 的 PingFang SC、Linux 的 Noto Sans CJK SC、Windows 的
Microsoft YaHei 等）。 如果在 Linux 上运行且中文显示为方框，请先安装中文字体：

The notebook's charts contain Chinese titles. It includes a font-fallback
routine that automatically picks an installed CJK font (PingFang SC on macOS,
Noto Sans CJK SC on Linux, Microsoft YaHei on Windows, etc.). On Linux, if
Chinese characters render as boxes, install a CJK font first:

```bash
# Debian / Ubuntu
sudo apt-get install fonts-noto-cjk
```

## 复现说明 / Reproducibility Notes

| 文件 / File        | 作用 / Purpose                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------ |
| `pyproject.toml`   | 声明项目元数据、Python 版本与直接依赖 / project metadata, Python version and direct dependencies |
| `uv.lock`          | `uv sync` 使用的锁文件，锁定整套环境 / lock file used by `uv sync` to pin the whole environment  |
| `requirements.txt` | 供 pip 用户使用的锁定依赖清单 / pinned dependency list for pip users                             |

直接依赖（`pyproject.toml` 中显式声明）与 Notebook 中 `import` 的包保持一致， 避
免依赖「顺带安装」的传递依赖而导致的复现问题。

The direct dependencies declared in `pyproject.toml` match exactly what the
notebook imports, so reproduction does not rely on packages that happen to be
pulled in transitively.
